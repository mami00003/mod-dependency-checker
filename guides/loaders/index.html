Forge / NeoForge / Fabric / Quilt の違いと選び方Forge vs NeoForge vs Fabric vs Quilt — which loader should you use?

最終更新: 2026年8月Last updated: August 2026

Modを動かすには「モッドローダー」という土台が必要です。現在の選択肢は主に4つあり、Modはどれか1つのローダー専用に作られています。だから最初にローダーを決めることが、遊べるModの範囲を決めることになります。

To run mods at all you need a mod loader underneath. There are four realistic choices today, and every mod is built for exactly one of them. So the loader you pick effectively decides which mods you can play.

4つの違いThe four, side by side

Slower to reach new Minecraft versions, and momentum has been shifting to NeoForge 1.20.1以前の定番Modpackで遊びたい人Playing established modpacks on 1.20.1 and earlier
NeoForge Forgeから分岐した後継。互換性の考え方はForge寄りで、新バージョン対応が速い。近年の新規Modはこちらが増えているA fork and de-facto successor to Forge. Similar philosophy, much faster to support new versions, and where most new Forge-style mods now land 最新バージョンで大型Modを使いたい人Using substantial mods on current versions

選び方の実際How to actually choose

理屈から選ぶより、遊びたいModが対応しているローダーに合わせるのが正解です。ローダーの優劣を比べても意味は薄く、目当てのModが片方にしか無いなら選択肢は最初から1つです。

Rather than comparing loaders in the abstract, follow the mods you actually want. Arguing about which loader is better is mostly wasted effort — if the mod you care about exists on only one of them, the decision is already made.

複数のModを組み合わせたい場合は、全部が同じローダーに対応しているかを先に確認してください。ここを見落とすと、あとで「1本だけ動かない」に必ずぶつかります。

If you are assembling a set, confirm up front that every mod supports the same loader. Skipping this check is exactly how you end up with one stubborn jar that refuses to load.

よくある誤解Common misconceptions

「ForgeのModはNeoForgeで動く」

"Forge mods work on NeoForge"

分岐直後の一時期は近かったものの、現在は別物です。配布ページの対応表記を確認してください。

They were close right after the split, but they have diverged. Check the stated support on the download page explicitly.

「ローダーは共存できる」

"You can run two loaders at once"

できません。ただしランチャーのプロファイルを分ければ、同じPCでForge用とFabric用の環境を持てます。mods フォルダも分けるのが安全です。

You cannot. You can, however, keep separate launcher profiles — one Forge, one Fabric — on the same machine, ideally with separate mods folders.

「バージョンさえ合えばどのローダーでも動く」

"If the version matches, any loader works"

バージョンとローダーは独立した条件です。両方が一致して初めて動きます。

Version and loader are independent requirements. Both must match before anything loads.
